FAQ

Common questions

How does Stacy send text messages?
Stacy uses the Textbelt SMS API. You can use the free tier (1 SMS/day for testing) or get a paid API key for unlimited messaging at textbelt.com. Messages are real SMS delivered to actual phone numbers.
Can each property have different settings?
Yes. Every property has its own configuration — different maintenance vendors, different policies, different parking rules, and separate tenant databases. Nothing gets mixed up.
What happens if Stacy can't handle a request?
Stacy is designed to escalate gracefully. If she encounters something she can't resolve, she texts you immediately with all the context and lets the tenant know their request has been forwarded to management.
Do my tenants need to install an app?
No. The tenant portal is a web app — tenants access it from any browser on any device. You generate an invite link and they activate their account in 30 seconds.
Is payment processing included?
Payment processing is currently in development and will be available soon. All other features — AI chat, parking enforcement, maintenance dispatch, SMS, and tenant management — are fully functional.
